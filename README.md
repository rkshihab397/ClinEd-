# ClinEd

A phone-first, offline-friendly medical learning companion built with HTML, CSS and JavaScript, then packaged as an Android APK with GitHub Actions.

## Build on GitHub
1. Upload the contents of this folder to the root of a GitHub repository.
2. Open **Actions** and enable workflows if GitHub asks.
3. Select **Build ClinEd APK** and tap **Run workflow**.
4. When the run succeeds, open it and download the `ClinEd-debug-APK` artifact.
5. Extract the ZIP and install `app-debug.apk`.

The APK is a learning aid, not a diagnostic or prescribing tool. Verify clinical information with current textbooks, local protocols and qualified clinicians.
